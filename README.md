# Flipkart Sales Performance Dashboard

![Flipkart Sales Performance Dashboard](images/Screenshot%202026-11-12%20094803.png)

## Project Overview
An interactive Power BI dashboard designed to analyze
sales, customer and order performance.

## Key KPIs
- Gross Sales
- Net Sales
- Total Orders
- Average Order Value

## Dashboard Analysis
- Monthly Sales Trend
- Sales by Product Category
- Top 10 Products
- Sales by Location
- Order Status
- Delivery Type
- Age Group

## 📈 Key Insights
- Analyzed 113,000 orders (2015-2020) with 25.4M in gross sales and an average gross order value of 224.97
- 27% of orders were returned, bringing gross sales of 25.4M down to 18.55M in net sales
- Health & Beauty (31.8%) and Fashion (29.5%) together drove 61% of total sales
- Electronics contributed only 9% of total sales

## 📂 Dataset
Public e-commerce sales dataset: 113,000 rows x 19 columns, covering orders from 2015 to 2020.
