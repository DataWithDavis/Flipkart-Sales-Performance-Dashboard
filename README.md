# Flipkart Sales Performance Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze
sales, customer and order performance.

## Key KPIs
- Gross Sales
- Net Sales
- Total Orders
- Average Order Value

## Dashboard Analysis
- Monthly Sales Trend
- Sales by Product Category
- Top 10 Products
- Sales by Location
- Order Status
- Delivery Type
- Age Group

## Tools Used
- Power BI
- SQL
- Python
- Excel
